# 💰 Debt Tracker Dashboard

## 📌 Project Overview

This project is an interactive Debt Tracker built in Microsoft Excel to help monitor debts, payments, outstanding balances, and financial progress.

---

## 🎯 Objective

The objective of this project is to:

- Track outstanding debts
- Monitor payment progress
- Visualise financial data
- Create an easy-to-use dashboard

---

## 🛠️ Tools Used

- Microsoft Excel
- Data Validation
- Formulas
- Conditional Formatting
- Charts
- Dashboard Design

---

## 📊 Features

- Debt Summary
- Payment Tracking
- Outstanding Balance
- Progress Monitoring
- Interactive Dashboard
